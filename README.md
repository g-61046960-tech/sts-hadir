# e-Keberadaan SMK Tinggi Segamat — Versi 7

Versi ini tidak mempunyai butang upload jadual waktu. Jadual induk daripada `Jadual Induk Guru V4.xlsx` telah ditukarkan kepada data terbina dalam di dalam `index.html`.

## Penggunaan
1. Buka aplikasi.
2. Klik **Upload Senarai Guru & Arus** dan masukkan fail Excel/CSV yang mempunyai lajur `Nama` dan `Arus`.
3. Pilih arus, nama guru, tarikh dan tempoh ketidakhadiran.
4. Untuk **Masa tertentu**, sistem membaca masa guru daripada jadual induk terbina dalam.
5. Klik **Hantar Maklumat**.

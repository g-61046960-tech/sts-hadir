# e-Keberadaan SMK Tinggi Segamat — Versi 6

## Perubahan utama
- Butang **Semak Guru Tidak Hadir** membuka dashboard secara terus.
- Tiada lagi borang username atau password pentadbir.
- Upload senarai guru dan arus melalui Excel/CSV.
- Upload jadual waktu melalui Excel/CSV; masa relief dipaparkan berdasarkan jadual yang dimuat naik.
- Rekod dihantar ke Google Apps Script yang telah ditetapkan dalam `index.html`.

## Format senarai guru
Lajur minimum:
- `Nama`
- `Arus` — `Perdana` atau `Tingkatan 6`

## Format jadual waktu
Lajur minimum:
- `Nama`
- `Arus`
- `Hari`
- `Masa`

Lajur pilihan:
- `Jam`
- `Kelas`
- `Subjek`

## Cara guna di GitHub Pages / Netlify
Muat naik keseluruhan kandungan folder ini, termasuk folder `assets`.
